# Wandr – Travel Planner

Wandr is a mobile travel-planning application developed using React Native, Expo, and TypeScript. It provides a centralised platform for organising trips, managing itineraries, tracking expenses, and preparing packing lists.

## Main Features

- Create, edit, and delete trips
- View upcoming and past trips
- Manage daily trip itineraries
- Track travel expenses and remaining budget
- Create packing lists and monitor packing progress
- Local data persistence using AsyncStorage

## Prerequisites

Before running the application, ensure that the following are installed:

- Node.js and npm
- Visual Studio Code (recommended)
- Expo Go on a compatible mobile device, or an Android/iOS simulator or emulator

## Installation and Setup

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the project's root directory.
4. Install the required dependencies:

   `npm install`

5. Start the Expo development server:

   `npx expo start`

6. Follow the terminal instructions to launch the application using Expo Go or a compatible simulator/emulator.

## Development Environment

- React Native
- Expo
- Expo Router
- TypeScript
- AsyncStorage

## Notes

- Trip information is stored locally using AsyncStorage.
- An internet connection may be required for installing dependencies and starting the development environment.
